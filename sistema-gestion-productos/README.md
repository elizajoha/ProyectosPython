Sistema de Gestión de Productos 🛒
Descripción
Este proyecto fue desarrollado como trabajo de preentrega durante mi formación en Python en Talento Tech.

Es una aplicación de consola que permite gestionar productos mediante un menú interactivo.
Funcionalidades
- Agregar productos.
- Visualizar productos registrados.
- Buscar productos por nombre.
- Eliminar productos.
- Salir del programa.
Conceptos de Python aplicados
- Variables y listas.
- Funciones.
- Condicionales (if, elif, else).
- Bucles (while y for).
- Validación de datos ingresados por el usuario.
- Conversión de tipos de datos.
- Búsqueda y manipulación de cadenas.
- Uso de enumerate() y pop().
Tecnologías utilizadas
- Python 3.
- Visual Studio Code.
- Git y GitHub.
Ejecución
Para ejecutar el programa desde la terminal:
python pre_entrega_proyecto.py
Estado del proyecto
Versión inicial desarrollada como práctica de formación. El proyecto podrá ampliarse con nuevas funcionalidades a medida que avance mi aprendizaje.
